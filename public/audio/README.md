# Original studio soundtracks

Neon Steps (120 BPM) and After Hours (90 BPM) are original mathematical synth compositions generated by `scripts/generate-audio.ts`. They contain no downloaded recordings or third-party loops. They may be used and redistributed with this project and with reels exported by it.

Beat zero is at audio time zero. BPM is a defined composition grid, not detected by AI. The same track metadata drives preview markers and exported edit timing. Regenerate with `npm run generate:audio`.
